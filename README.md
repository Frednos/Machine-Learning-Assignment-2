# Machine Learning – Assignment 2

## About the Project

This repository contains our solution to Assignment 2 in Machine Learning, focusing on binary classification of diabetes using Python.

The project involves exploring a diabetes dataset, analyzing relationships between health-related features and diabetes, training classification models, and evaluating their performance.

## Repository Contents

**Main files:**

- `Assignment_2.ipynb` – The main Jupyter Notebook containing our Python code, data analysis, visualizations, model training, evaluation, and answers to the assignment questions.
- `diabetes_binary_classification_data.csv` – The dataset used for the Machine Learning models.

**Additional files:**

- `Assignment_2_Diabetes_Classification.docx` – Assignment instructions and questions.
- `Diabetes_Understanding_the_Dataset.docx` – Guide explaining the dataset and its features.
- `confusion_matrix_thresholds.png` – Visualization of confusion matrices at different classification thresholds.
- `.gitignore` – Specifies files and folders that Git should ignore.

## How to Run

1. Clone or download the repository.
2. Open `Assignment_2.ipynb` in Jupyter Notebook or PyCharm.
3. Make sure `diabetes_binary_classification_data.csv` is in the same folder.
4. Install the required Python libraries.
5. Run the notebook cells in order.
